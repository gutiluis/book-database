# Inventory bookstore with SQLAlchemy

sqlalchemy script to build a db in sqlite with an interactive menu for edition

---

## How it works:

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```
